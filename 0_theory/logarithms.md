# Logarithms

## Logarithms

* Basic definition:
  $$\log_a(b) = x \iff a^x = b$$
* Product rule:
  $$\log(a \times b) = \log a + \log b$$
* Quotient rule:
  $$\log\left(\frac{a}{b}\right) = \log a - \log b$$
* Power rule:
  $$\log(a^k) = k \log a$$
* Base change formula:
  $$\log_a(b) = \frac{\log b}{\log a}$$
* Number of digits in $N$:
  $$\text{Digits} = \lfloor\log_{10}(N)\rfloor + 1$$
* Number of digits in $N!$:
  $$\text{Digits} = \lfloor\log_{10}(1) + \log_{10}(2) + \dots + \log_{10}(N)\rfloor + 1$$
* $\log_2(N)$ represents the number of times you can divide $N$ by 2.
