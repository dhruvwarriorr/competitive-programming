# In-Time / Out-Time (Graph DFS Timestamps)

Assign DFS entry and exit times for each node.

### Use Cases

- Ancestor style checks (mostly on trees)
- Subtree/event interval tricks
- Offline query ordering

- **Time Complexity:** $O(N + M)$
- **Space Complexity:** $O(N)$
